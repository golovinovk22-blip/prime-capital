# PRIME CAPITAL — стартовый Telegram Mini App

Это стартовый **демонстрационный** проект: интерфейс, навигация и серверный каркас.
Он НЕ принимает реальные деньги, не создаёт реальные инвестиции и не обещает доходность.
Платёжные операции намеренно не реализованы до юридической и платёжной проверки.

## Что уже работает
- вкладки «Обзор», «Активы», «Операции», «Профиль»;
- формы пополнения/вывода в демонстрационном режиме (без платежей и изменения реальных балансов);
- адаптивный тёмный интерфейс;
- серверный endpoint `/api/health`;
- проверка подписи `Telegram.WebApp.initData` на сервере;
- SQL-схема для будущего учёта пользователей, операций и инвестиций.

## Запуск на iPhone через Replit
1. Открой https://replit.com/ в Safari и войди в аккаунт.
2. Создай Repl типа Node.js либо импортируй этот ZIP в новый проект.
3. В корне проекта открой Shell и выполни `npm install`.
4. В Secrets добавь `BOT_TOKEN` (токен BotFather) и `DATABASE_URL` (если подключишь PostgreSQL).
   Не вставляй токен в исходный код и никому его не отправляй.
5. Для локального интерфейса можно запустить `npm run dev`. Для публикации используй Deployments/Publish и получи HTTPS URL.
6. Только после получения публичного HTTPS URL открой @BotFather → `/setmenubutton` → выбери бота → текст `Открыть приложение` → вставь HTTPS URL.

## Важно
- Для production Telegram требует HTTPS.
- Сервер должен проверять `initData` и не доверять `initDataUnsafe` как доказательству личности.
- До реального запуска инвестиций проверьте статус компании/оператора, применимые разрешения и правила Банка России, договоры с инвесторами, KYC/AML, налоги, защиту персональных данных и допустимость конкретных платёжных каналов.
- Не подключайте карты/криптовалюту через самодельный обработчик. Нужен договор с надлежащим провайдером и проверка правовой допустимости.
- Ежедневные начисления в реальной версии должны отражать фактический результат/обязательства по документам продукта. В этом шаблоне доходность не начисляется.
